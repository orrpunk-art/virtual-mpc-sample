# Virtual MPC Sample

[English](README.md) · **Русский** · [中文](README.zh-CN.md)

Стоковая прошивка Akai MPC Sample (1.3.0.12) без изменений работает в QEMU, а весь прибор
открывается в браузере: верхняя панель с живым экраном, пэдами, ручками и кнопками, задняя
панель с разъёмами, слот SD и USB-C. Работает на macOS, Linux и Windows; быстрее всего на
Apple Silicon.

виртуальных устройств](docs/img/panel.jpg)

|---|---|---|---|
| ![](docs/img/screen-factory-library.png) | ![](docs/img/screen-trim.png) | ![](docs/img/screen-shutdown.png) | ![](docs/img/screen-shutting-down.png) |

> **Неофициальный проект.** Не связан с inMusic Brands и Akai Professional, ими не одобрен и не
> поддерживается. **В репозитории нет ни прошивки, ни заводского контента**: нужна своя копия
> обновления прошивки, а для заводской библиотеки — свой MPC Sample.

## Зачем это

- **Собирать и проверять моды, не рискуя прибором.** Пакеты SD autorun запускаются так же,
  как на MPC (штатным раннером прошивки); сломанный пакет стоит одного `lab.py reset`, а не
  восстановления прибора.
- **Отлаживать внутри стокового приложения.** Root-шелл, библиотеки через `LD_PRELOAD`,
  strace, сырые байты панели управления.
- **Изучать прибор.** [stock-map/](stock-map/README.md) — все стоковые экраны на английском,
  русском и китайском: что делает каждая кнопка и каждое сочетание с SHIFT.

[![Карта стоковых экранов: каждая кнопка и сочетание с SHIFT и экран, который они открывают](docs/img/stock-map.jpg)](stock-map/README.md)

Карта стоковых экранов: 56 разделов, 383 снимка из этого эмулятора, одна HTML-страница,
работает без интернета (откройте `stock-map/index.html`).

## Что работает

- Стоковый rootfs байт-в-байт, открытый через dm-verity со стоковым root hash из подписанного
  образа ядра; стоковые юниты systemd запускают стоковое приложение.
- Экран 320×240, пэды, ручки, кнопки и колесо DATA — по тому же протоколу UART, на котором
  говорит микроконтроллер панели.
- Звук на странице в браузере; сэмплирование со входов страницы.
- SD-карта (любая папка на компьютере), пакеты SD autorun, заводская библиотека.
- USB-C: собственная USB-сеть прибора (192.168.155.1), USB MIDI, root SSH для пакетов
  сообщества.
- Кнопка питания как на приборе: приложение спрашивает, сохраняет проект, выключается.

Пока нет: USB-аудио через USB-C, проверки на Windows, других версий прошивки. См.
[план развития](#план-развития).

## Быстрый старт

Нужны QEMU 9+, Docker (только для сборки), Python 3.9+ и клиент OpenSSH.

1. Клонируйте репозиторий.
2. Положите разделы прошивки в `firmware/extracted/` (игнорируется git):
   `part1` (boot), `part2` (rootfs), `parr` (recovery), извлечённые из образа inMusic
   `MPCSAMPLE-1.3.0.12-update.img`. Сборка сверяет их с `inputs.sha256`.
   Распаковщика образа обновления в репозитории пока нет
   ([подробнее](docs/CUSTOM_FIRMWARE.md#4-another-stock-firmware-version)).
3. Соберите и запустите:

   ```bash
   python3 lab.py build    # Docker: ядро (~15 мин один раз), аудиомост, образы дисков
   python3 lab.py run      # виртуальная машина; панель запускается тоже
   ```

4. Откройте **http://127.0.0.1:8765/** и кликните один раз, чтобы пошёл звук.

```bash
python3 lab.py ssh               # root-шелл в ВМ
python3 lab.py autorun PKG.zip   # запустить пакет SD autorun
python3 lab.py stop              # кнопка питания + «Yes»: сохранить, выключить, закрыть QEMU
python3 lab.py reset             # следующий запуск с чистой eMMC
```

На Windows — `py lab.py ...`. На macOS запускайте из Terminal.app или iTerm, а не из
терминала IDE или другого приложения: macOS может притормаживать такой процесс, и в звуке
появляются щелчки.

## План развития

Помощь нужна в любом из пунктов:

- **Распаковщик прошивки** для образа обновления `AZ0x`, чтобы настройка шла одной командой.
  Сейчас это главный барьер для новых пользователей.
- **Запуск на Windows и Linux.** Код для них есть, но запускалось только на macOS (Apple
  Silicon).
- **Готовые ядро и аудиомост** в релизах, чтобы не ждать 15 минут сборки в Docker.
- **CI**, который гоняет `make test` (самопроверки лаборатории и панели) на каждый pull request.
- **USB-аудио (UAC2)** на эмулируемом USB-C; сейчас оно отключено, потому что не
  поднимается на USB-контроллере лаборатории.
- **Меньше щелчков в звуке** при программной эмуляции (TCG) и tickless-гость под HVF без
  платы за `nohz=off`.
- **Другие версии прошивки** и проверка того, что в каждой меняется.
- **MIDI с хоста** на странице панели (Web MIDI на задние MIDI-разъёмы).

Перед большим изменением откройте issue. См. [CONTRIBUTING.md](CONTRIBUTING.md).

документации получены на одном Mac (Apple Silicon, прошивка 1.3.0.12) в указанные даты.

## Правовое

- Akai Professional и MPC — товарные знаки inMusic Brands, Inc. Здесь они используются только
  для того, чтобы назвать прибор, который эмулирует лаборатория.
- Лаборатория только читает предоставленные вами файлы прошивки, монтирует их только для
  чтения и никогда не пишет в физический прибор.
- Снимки экранов стокового приложения приведены для документации и совместимости.
